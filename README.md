# Econometrics - Notas basadas en Hansen

Apuntes personales de los libros **Probability and Statistics for Economists** y **Econometrics** de Bruce E. Hansen con aplicaciones en R: cada capítulo combina los apuntes teóricos con código para practicar (implementaciones desde cero de los estimadores, comparación con paquetes estándar y simulaciones).

## 🐙 Contenido

Este repositorio contiene notas y resúmenes de:

-   **Probability and Statistics for Economists** (18 capítulos + apéndice)
-   **Econometrics** (29 capítulos en seis partes + 2 apéndices)

## 🐢 Flujo de trabajo

1. Editar los `.qmd` y revisar con `quarto preview`.
2. Renderizar con `quarto render --to html` para actualizar `_freeze/` (resultados del código R).
3. Hacer commit y push a `main` (incluyendo `_freeze/`). GitHub Actions publica la página.

El PDF se genera solo en local con `quarto render --to pdf`.
